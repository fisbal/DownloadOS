# DownloadOS

**Download**OS — the MartinB OS APK installer for Android.

- **My apps**: lists every `fisbal` repo whose latest GitHub Release has an `.apk`, shows installed / update available, and installs or updates in one tap (Android 12+: updates of apps it installed happen silently).
- **Link**: paste or *Share → DownloadOS* any direct `.apk` link, a `github.com/owner/repo` page, or just `owner/repo`.
- **File**: install an `.apk` already on the phone, or *Open with → DownloadOS*.

Every push to `main` builds a signed APK and publishes it as the latest Release.
Download: https://github.com/fisbal/DownloadOS/releases/latest
